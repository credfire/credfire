Buzzcut

Un outil personnel pour découper des vidéos en clips courts.

Buzzcut est une application Windows personnelle, non distribuée. Elle sert à son auteur à repérer les meilleurs moments d'une vidéo, à les découper en clips verticaux sous-titrés, puis à les publier sur sa propre chaîne YouTube.

La publication sur YouTube passe par les services API de YouTube (YouTube API Services). Buzzcut envoie uniquement les vidéos que son utilisateur choisit de publier, sur sa propre chaîne, après un clic de sa part. Rien n'est publié automatiquement.

Buzzcut n'a pas de serveur et ne collecte aucune donnée. Le détail est dans les règles de confidentialité.
